Logotype slot for the Home screen (shown instead of the panda-train logo).

Put one file per edition in this folder:
  en.webp   (or en.png / en.svg)   -> "Choo Choo Pop"      (English build)
  fa.webp   (or fa.png / fa.svg)   -> "هو هو چی چی"        (Persian build)

Transparent background, about 1000 px wide is plenty. It is shown at up to 380 px wide.
If a file is missing, the Home screen draws the title as styled text so nothing is ever empty.
