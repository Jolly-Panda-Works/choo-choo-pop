# Choo Choo Pop · هو هو چی چی

بازی پازل ریل‌چینی برای کودکان (رده‌ی سنی ۷ سال)، کاملاً **top-down** (بوم دوبعدی + اسپرایت‌های PNG)، React + Capacitor (اندروید) و بیلد خودکار با GitHub Actions.
شناسه‌ی اپ: `com.jollypanda.choochoopop`

## دو نسخه‌ی خروجی
| نسخه | نام در گوشی | شناسه‌ی اپ | زبان |
|---|---|---|---|
| `en` | Choo Choo Pop | `com.jollypanda.choochoopop` | فقط انگلیسی |
| `fa` | هو هو چی چی | `com.jollypanda.choochoopop.fa` | فقط فارسی (فونت وزیرمتن داخل اپ، رقم‌های فارسی، راست‌به‌چپ) |

نسخه موقع بیلد انتخاب می‌شود (`VITE_EDITION`)؛ دکمه‌ی تغییر زبان وجود ندارد.

```bash
npm install
npm run dev            # مرورگر، انگلیسی
npm run dev:fa         # مرورگر، فارسی
npm run test:levels    # هر ۲۰ مرحله: حل‌پذیر + جواب یکتا + منحنی سختی + قانون super hard + آموزش

# اندروید (بعد از هر بار بیلد وب، همان نسخه را سینک کن)
npm run cap:sync:en && (cd android && ./gradlew assembleDebug -PEDITION=en)
npm run cap:sync:fa && (cd android && ./gradlew assembleDebug -PEDITION=fa)
```
در GitHub Actions هر دو نسخه با هم (matrix) ساخته می‌شوند و دو آرتیفکت جدا می‌دهند. برای APK/AAB امضاشده چهار Secret بساز:
`KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`.

## ساختار بازی (نسخهٔ ۱.۲)
- **۴ استیج** (شهر/روستا)، هر استیج **۲۰ ایستگاه** (= ۲۰ مرحله). فعلاً فقط استیج ۱ ساخته شده؛ بقیه روی نقشه «به‌زودی» هستند. تنظیم: `src/game/stages.js`.
- جریان صفحه‌ها: **خانه ← نقشهٔ استیج‌ها ← ایستگاه‌های استیج ← بازی**. فروشگاه و تنظیمات از خانه (و فروشگاه از نوار سکه‌ی همه‌ی صفحه‌ها) باز می‌شوند.
- هر ایستگاه سه حالت دارد: **رد شده** (۱ تا ۳ ستاره بالای آن)، **فعلی** (حلقه‌ی چشمک‌زن + پاندا)، **قفل**. شکل/رنگ گره به درجهٔ سختی بستگی دارد: ساده (سبز)، نرمال (آبی)، سخت (نارنجی)، **super hard** (بنفش، بزرگ‌تر، تاج).
- درجه‌ها: ۱–۵ آموزش (۳×۳، شبیه ساده)، ۶–۱۰ ساده، ۱۱–۱۵ نرمال، ۱۶–۱۹ سخت، **۲۰ super hard** (۶×۶، حدود ۹٬۸۰۰ گره‌ی جست‌وجو؛ ۲× سخت‌ترین مرحلهٔ سخت). در هر استیج *بعدی* دو مرحله‌ی آخر (۱۹ و ۲۰) super hard می‌شوند؛ فقط در استیج ۱ مرحلهٔ آخر. `npm run test:levels` همین قانون را چک می‌کند.
- **استوری**: بار اول (و از تنظیمات) ۵ اسلاید با پاندا: رسیدن پاندا (ویدیو) ← ریل‌ها به‌هم‌ریخته و قطارها از ورودی به خروجی نمی‌رسند ← تونل سبز/قرمز ← «کمکم می‌کنی؟» ← شروع. بعد مستقیم وارد مرحلهٔ ۱ می‌شود.
- **پاندا** همراه بازیکن است: حباب آموزش (مراحل ۱–۵)، پاپ‌آپ شروع، برد، شکست، نبودن راهنما، قفل والدین.
- **پاپ‌آپ‌ها**: شروع مرحله، برد (ستاره + سکه)، شکست، «راهنما تمام شد».
- **شکست**: هر بار که قطار به خروج برسد ولی عددها درست نباشد یک قلب از ۳ قلب کم می‌شود (در آموزش نه). با صفر شدن قلب‌ها پاپ‌آپ شکست می‌آید؛ «دوباره» مرحله را از اول می‌چیند. ستاره: ۳ اگر بدون راهنما و بدون اشتباه، ۲ اگر مجموع (راهنما + اشتباه) ≤ ۲، وگرنه ۱.

## اقتصاد و فروشگاه (`src/config.js`)
- سکه‌ی مرحله (فقط بار اول): پایهٔ درجه (آموزش ۸، ساده ۱۰، نرمال ۱۴، سخت ۱۸، super ۴۰) + ۵ به‌ازای هر ستاره. تکرار با ستارهٔ بیشتر: ۵ به‌ازای هر ستارهٔ اضافه.
- راهنما: ۵ تا در شروع، +۱ رایگان به‌ازای هر ۲ مرحلهٔ اصلی؛ **بسته‌ی کوچک** (۳ راهنما، ۶۰ سکه) و **بزرگ** (۱۰ راهنما، ۱۵۰ سکه).
- بسته‌های سکه با پول واقعی (۲۰۰ / ۷۰۰ / ۱۶۰۰)، **حذف تبلیغات**، **ظاهر قطار** و **ظاهر پاندا** (با سکه). خرید با پول واقعی پشت «قفل والدین» (سؤال ضرب) است.
- **تبلیغ پاداشی اختیاری**: «ویدیو ببین، ۱ راهنما بگیر» در فروشگاه و پاپ‌آپ «راهنما تمام شد».
- **تبلیغ بین مراحل**: بعد از هر **۴ یا ۵** مرحله‌ی تمام‌شده (تصادفی، ذخیره‌شده در سیو)، هنگام رفتن از پاپ‌آپ برد به مرحلهٔ بعد/نقشه. قابل رد کردن است، در آموزش نمی‌آید، با «حذف تبلیغات» خاموش می‌شود.

## وصل کردن سرویس تبلیغ و خرید (بعداً)
دو آداپتور کوچک هست و بازی را عوض نمی‌کند:
- `src/services/ads.js` → `registerAdsProvider({ init, isRewardedReady, showInterstitial, showRewarded })`
- `src/services/billing.js` → `registerBillingProvider({ init, getPrices, purchase, restore })`

سرویس را در `src/main.jsx` قبل از `render` ثبت کن (مثلاً بر اساس `EDITION`: بازار/مایکت/تپسل برای `fa`، Google Play برای `en`).
**بدون ارائه‌دهنده در نسخهٔ نهایی** هیچ تبلیغی نشان داده نمی‌شود، دکمه‌ی «ویدیو» پنهان است و خرید غیرفعال است (هیچ‌وقت سکه‌ی مجانی داده نمی‌شود). در `npm run dev` یا با `VITE_MOCK_SERVICES=1` تبلیغ و خرید **آزمایشی** فعال است (`src/ui/AdHost.jsx`).

## قوانین بازی
- جدول یک تونل سبز (ورود) و یک تونل قرمز (خروج) دارد؛ با کشیدن انگشت یک مسیر پیوسته بین آن‌ها بچین.
- عدد کنار هر سطر و بالای هر ستون = تعداد دقیق ریل آن خط. عدد سبز یعنی خط کامل است.
- خانه‌های ستاره‌دار حتماً جزو مسیر هستند. برای پاک کردن، انگشت را روی مسیر به عقب بکش.
- هر مرحله فقط **یک** جواب دارد (با solver تست می‌شود).

## آموزش و ایستگاه‌های اول (استیج ۱)
| ایستگاه | اندازه | درجه |
|---|---|---|
| ۱–۵ | ۳×۳ | آموزش (کشیدن، پیچ، عددها، پاک کردن اشتباه، ستاره) |
| ۶–۱۰ | ۳×۴ تا ۴×۵ | ساده |
| ۱۱–۱۵ | ۴×۵ تا ۵×۵ | نرمال |
| ۱۶–۱۹ | ۵×۶ تا ۶×۶ | سخت |
| ۲۰ | ۶×۶ | **super hard** |

برای ساخت مرحله‌ها: `PLAN` در `scripts/build-levels.mjs` را بنویس، `node scripts/build-levels.mjs`، بعد `npm run test:levels`.
آموزش در `src/game/tutorial.js` است (انگشت متحرک، حلقه‌ی چشمک‌زن، حباب پاندا).

## چک‌لیست رده‌ی سنی ۷ سال (مهم: حالا تبلیغ و خرید دارد)
- تبلیغ: فقط شبکه‌های مجاز برای کودکان (Google Play Families / برنامهٔ کودکان بازار)، **بدون تبلیغ شخصی‌سازی‌شده**، تبلیغ‌ها قابل رد شدن و فقط بین مراحل؛ هیچ تبلیغی در آموزش، وسط بازی یا بعد از شکست نیست.
- خرید درون‌برنامه‌ای: قفل والدین (انجام شد)، بدون شمارش معکوس/فشار؛ فروشگاه فقط با دکمهٔ فروشگاه باز می‌شود، نه خودکار بعد از باخت.
- مجوز `INTERNET` را Capacitor پیش‌فرض اضافه می‌کند؛ SDK تبلیغ/خرید هر مجوز دیگری بخواهد باید در فرم Data Safety اعلام شود.
- در فرم Play Console گروه سنی را «مخصوص کودکان / Families» اعلام کن (جزئیات در سند پیش‌بینی درآمد).
