# Choo Choo Pop · هو هو چی چی

بازی پازل ریل‌چینی آفلاین برای کودکان (رده‌ی سنی ۷ سال) با React Three Fiber + Capacitor (اندروید) و بیلد خودکار با GitHub Actions.
شناسه‌ی اپ: `com.jollypanda.choochoopop`

## دو نسخه‌ی خروجی
| نسخه | نام در گوشی | شناسه‌ی اپ | زبان |
|---|---|---|---|
| `en` | Choo Choo Pop | `com.jollypanda.choochoopop` | فقط انگلیسی |
| `fa` | هو هو چی چی | `com.jollypanda.choochoopop.fa` | فقط فارسی (فونت وزیرمتن داخل اپ، رقم‌های فارسی، راست‌به‌چپ) |

نسخه موقع بیلد انتخاب می‌شود (`VITE_EDITION`)؛ دکمه‌ی تغییر زبان وجود ندارد.

```bash
npm install
npm run dev            # مرورگر، انگلیسی
npm run dev:fa         # مرورگر، فارسی
npm run test:levels    # ۲۰ مرحله: حل‌پذیر + جواب یکتا + منحنی سختی + قوانین آموزش

# اندروید (بعد از هر بار بیلد وب، همان نسخه را سینک کن)
npm run cap:sync:en && (cd android && ./gradlew assembleDebug -PEDITION=en)
npm run cap:sync:fa && (cd android && ./gradlew assembleDebug -PEDITION=fa)
```
در GitHub Actions هر دو نسخه با هم (matrix) ساخته می‌شوند و دو آرتیفکت جدا می‌دهند. برای APK/AAB امضاشده چهار Secret بساز:
`KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`.

## قوانین بازی
- جدول یک فلش سبز (ورود) و یک فلش قرمز (خروج) دارد؛ با کشیدن انگشت یک مسیر پیوسته بین آن‌ها بچین.
- عدد کنار هر سطر و بالای هر ستون = تعداد دقیق ریل آن خط. عدد سبز یعنی خط کامل است.
- خانه‌های ستاره‌دار حتماً جزو مسیر هستند. برای پاک کردن، انگشت را روی مسیر به عقب بکش.
- هر مرحله فقط **یک** جواب دارد (با solver تست می‌شود).

## بخش اول: ۲۰ مرحله
| مرحله | اندازه | برچسب | هدف |
|---|---|---|---|
| ۱–۵ | ۳×۳ | آموزش | ۱ کشیدن از فلش سبز تا قرمز · ۲ پیچ · ۳ عددها · ۴ پاک کردن اشتباه · ۵ خانه‌ی ستاره |
| ۶–۱۰ | ۳×۴ تا ۴×۵ | آسان | |
| ۱۱–۱۵ | ۴×۵ تا ۵×۵ | متوسط | |
| ۱۶–۲۰ | ۵×۶ تا ۶×۶ | سخت | (بزرگ‌ترین جدول ۶×۶ با ۳ ستاره‌ی کمکی) |

سختی اندازه‌گیری می‌شود: `scripts/build-levels.mjs` برای هر مرحله یک بازه‌ی «تعداد گره‌های جست‌وجوی solver» دارد و فقط پازلی را قبول می‌کند که در بازه‌ی همان مرحله باشد؛ پس منحنی فقط بالا می‌رود. `npm run test:levels` جدول را چاپ و رعایت منحنی را چک می‌کند.
آموزش (مرحله ۱–۵) در `src/game/tutorial.js` است: پیام کوتاه، انگشت متحرک، حلقه‌ی چشمک‌زن دور عددها/ستاره، و در مرحله ۴ بازی با یک ریل اشتباه شروع می‌شود تا کودک «برگرداندن» را تجربه کند. در آموزش راهنما رایگان است و همیشه ۳ ستاره می‌دهد.

برای مرحله‌ی بیشتر: `PLAN` را در `scripts/build-levels.mjs` گسترش بده، `node scripts/build-levels.mjs`، سپس `TOTAL_LEVELS` در `src/game/constants.js` را هماهنگ کن.

## چک‌لیست رده‌ی سنی ۷ سال
- بدون تبلیغ، بدون آنالیتیکس، بدون SDK شخص ثالث، بدون جمع‌آوری اطلاعات؛ نسخه‌ی قبلی «چک آپدیت از GitHub» و لینک بیرونی حذف شد.
- هیچ باخت یا تایمری نیست؛ متن‌ها کوتاه و ساده‌اند؛ دکمه‌ها بزرگ‌اند.
- راهنما: ۵ تا در شروع + یکی به‌ازای هر ۲ مرحله‌ی اصلی.
- مجوز `INTERNET` را Capacitor پیش‌فرض اضافه می‌کند و هیچ جای کد از آن استفاده نمی‌کند.
- هنگام اضافه کردن خرید درون‌برنامه‌ای: قفل والدین، بدون پیشنهاد در آموزش/بعد از باخت، بدون شمارش معکوس؛ و در فرم Play Console گروه سنی را «مخصوص کودکان / Families» اعلام کن (جزئیات در سند پیش‌بینی درآمد).
