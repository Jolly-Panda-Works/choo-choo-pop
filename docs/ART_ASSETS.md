# لیست تصاویر و صداهای مورد نیاز (Choo Choo Pop)

فعلاً بازی با هندسه‌های ساده‌ی سه‌بعدی (جعبه، استوانه، کره) و گرافیک CSS ساخته شده و هیچ فایل تصویری لازم ندارد.
هر وقت آرت نهایی آماده شد، فایل‌ها را با همین نام‌ها در مسیر پیشنهادی بگذار تا جایگزین شوند.

سبک کلی: شاد، رنگ‌های اشباع پاستلی، لبه‌های گرد، کارتونی و بدون خط‌های تیز. پالت اصلی:
زرد `#FFD43B`، آبی `#4DABF7`، مرجانی `#FF6B6B`، سبز چمنی `#8EE07A`، قهوه‌ای چوب `#A9693A`، کرم `#FFFAF0`.

## ۱) اپ و استور (اولویت بالا)
| فایل | اندازه | توضیح |
|---|---|---|
| `resources/icon.png` | 1024×1024 | آیکون اصلی؛ لوکوموتیو خندان روی پس‌زمینه‌ی آبی، بدون گوشه‌ی گرد (سیستم برش می‌دهد) |
| `resources/icon-foreground.png` | 1024×1024 | لایه‌ی جلویی آیکون Adaptive؛ طرح اصلی داخل دایره‌ی مرکزی 66٪ |
| `resources/icon-background.png` | 1024×1024 | پس‌زمینه‌ی تخت آبی آسمانی |
| `resources/splash.png` | 2732×2732 | اسپلش؛ لوگوی بازی وسط، رنگ زمینه `#8FD6FF` |
| `store/feature-graphic.png` | 1024×500 | بنر گوگل‌پلی |
| `store/screenshot-1..6.png` | 1080×1920 | اسکرین‌شات‌ها با تیتر (مثل نمونه‌های رفرنس) |

بعد از گذاشتن فایل‌ها: `npx @capacitor/assets generate --android`

## قواعد کلی
- فرمت مدل‌ها: GLB (Draco یا بدون فشرده‌سازی)، حداکثر 5 هزار مثلث برای هر قطعه
- فرمت تصاویر: PNG یا WebP با پس‌زمینه‌ی شفاف، همه‌چیز آفلاین و داخل اپ
- حجم کل آرت زیر 10 مگابایت بماند
