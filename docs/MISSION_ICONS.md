# آیکون‌های ماموریت‌ها (برای تولید)

هر ماموریت یک آیکون می‌خواهد که داخل حباب شیشه‌ای ردیف ماموریت (`m-row` در منوی Missions) نمایش داده می‌شود.

- **مسیر فایل:** `public/choo-choo-pop-assets/art/missions/<id>.webp`
- **اندازه:** ۵۱۲×۵۱۲، پس‌زمینهٔ شفاف، سوژه وسط و حدود ۸۰٪ کادر (حاشیهٔ شفاف دور آن)
- **سبک:** مثل بقیهٔ آرت بازی — براق، کارتونی، لبهٔ ضخیم‌تر، رنگ‌های روشن؛ بدون متن
- تا وقتی فایل نیامده، بازی خودش یک ایموجی جایگزین نشان می‌دهد (در `src/screens/Missions.jsx`).

## ماموریت‌های روزانه (۸ نوع؛ هر روز ۳ تا)

| id (نام فایل) | ماموریت | پیشنهاد آیکون |
|---|---|---|
| `dVisit` | سلام دوباره! — امروز بازی را باز کن | پاندا در حال سلام دادن کنار تقویم/خورشید صبحگاهی |
| `dLevels` | سرعت ایستگاه — N ایستگاه را درست کن | لوکوموتیو آبی در حال حرکت با خطوط سرعت |
| `dStars` | ستاره‌جمع‌کن — N ستاره بگیر | سه ستارهٔ طلایی براق روی هم |
| `dPerfect` | بی‌نقص — در N ایستگاه ۳ ستاره بگیر | جام طلایی با سه ستاره |
| `dNoHint` | بدون کمک — بدون راهنما حل کن | لامپ خاموش خط‌خورده یا مغز بامزه |
| `dNoMistake` | چشم تیز — بدون اشتباه | هدف دایره‌ای با تیر در مرکز (دارت) |
| `dCoins` | سکه‌جمع‌کن — N سکه به‌دست بیاور | کیسهٔ سکه با سکه‌های پنجه‌ای صورتی/طلایی |
| `dPower` | پاورآپ! — N پاورآپ استفاده کن | عصای جادویی با جرقه (یا ستاره و چشم و پاک‌کن در یک دسته) |

## ماموریت‌های هفتگی (۸ نوع؛ هر هفته ۳ تا)

| id (نام فایل) | ماموریت | پیشنهاد آیکون |
|---|---|---|
| `wLevels` | استاد ایستگاه — N ایستگاه در هفته | ساختمان ایستگاه قطار با پرچم |
| `wStars` | شکارچی ستاره — N ستاره در هفته | تور/تلسکوپ و ستارهٔ درخشان |
| `wPerfect` | راننده‌ی طلایی — ۳ ستاره در N ایستگاه | کلاه راننده‌ی طلایی با تاج کوچک |
| `wDays` | راننده‌ی همیشگی — در N روز مختلف بازی کن | تقویم هفتگی با تیک‌های سبز |
| `wNoHint` | مغز بزرگ — بدون راهنما | مغز صورتی با لامپ درخشان |
| `wNoMistake` | چشم عقاب — بدون اشتباه | چشم عقاب/عینک ذره‌بین |
| `wCoins` | قطار گنج — N سکه در هفته | واگن قطار پر از سکه |
| `wPower` | هفتهٔ جادویی — N پاورآپ | توپ بلورین جادویی |

## آیکون‌های دیگری که می‌توانی جایگزین کنی (اختیاری)
- لامپ `ui/bulb.png`، پاورآپ‌ها (ستاره، پاک‌کن، چشم): الان با SVG در `src/ui/icons.jsx → PowerIcon` رسم می‌شوند. اگر آیکون رنگی بدهی، فایل `art/ui/pw-star.png`، `pw-eraser.png`، `pw-peek.png` (۲۵۶×۲۵۶) را به‌جای SVG وصل کن.

## برنامهٔ ۳ ماههٔ ماموریت‌ها
- ماه اول (روز ۱ تا ۳۰ از اولین اجرا): هدف‌های آسان؛ ماه دوم: متوسط؛ ماه سوم: سخت‌تر. جایزهٔ سکه هم با هر ماه بیشتر می‌شود.
- هر روز ۳ ماموریت به‌ترتیب چرخشی از ۸ نوع انتخاب می‌شود و هر هفته ۳ ماموریت هفتگی (۱۳ هفته).
- بعد از ۹۰ روز (۱۳ هفته) ماموریت‌ها از همان مجموعه **تصادفی** انتخاب می‌شوند (با seed تاریخ، پس در طول روز ثابت‌اند) و سطح هدف هم تصادفی است.
- ماموریت «پاورآپ» تا وقتی بازیکن به استیج ۲ نرسیده در لیست نمی‌آید.
- کد: `src/game/missions.js`
