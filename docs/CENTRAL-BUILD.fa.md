# بیلد مرکزی Android

این بازی از قرارداد game-template استفاده می‌کند، اما پروژهٔ Android ثبت‌شده و flavorهای موفق بازار و مایکت حفظ شده‌اند. شناسهٔ انتشار همان `com.jollypanda.choochoopop` است؛ game.config.json نیز عمداً همین شناسهٔ موجود را نگه می‌دارد.

- توسعه روی main و بیلد استورها روی Iranian-store است. تغییرات main را به Iranian-store merge کنید؛ branch استورها را به main برنگردانید.
- در game-builds عمومی، ثبت choo-choo-pop به همین برنچ اشاره می‌کند. nativeProject=committed مانع پاک‌شدن پروژهٔ بومی موجود هنگام سوییچ بین flavorها می‌شود.
- نسخهٔ بعد از بالاترین تگ main/استورها انتخاب می‌شود؛ اولین مهاجرت 1.6.4 و versionCode=1006004 است. شمارهٔ نسخهٔ نمایش‌داده‌شده در بازی نیز نسخهٔ همین بیلد است.
- همان چهار Secret امضای موجود، رمزگذاری‌شده با کلید عمومی Environment مقصد، به Environment choo-choo-pop منتقل شده‌اند. هیچ کلید جدیدی ساخته نشده است. کلیدهای عمومی خرید نیز از تنظیمات موجود آمده‌اند.
- هر Release شامل APK/AAB بازار، APK/AAB مایکت، APK مستقل standalone-debug و SHA256SUMS است. نسخهٔ Debug قابل دیباگ، با شناسهٔ com.jollypanda.choochoopop.debug و بدون SDK بازار/مایکت است. نسخهٔ اصلی و Debug کنار هم نصب می‌شوند.
- نسخهٔ مستقل فقط برای QA است؛ خرید، ورود و به‌روزرسانی استوری در آن غیرفعال است. کلید امضای دیباگ runner ممکن است عوض شود؛ در صورت تعارض امضا، نسخهٔ Debug قبلی را حذف کنید.
- BUILD_MODE=central بیلدهای تکراری قدیمی را غیرفعال می‌کند. مسیر مستقل قبلی با تغییر این متغیر دوباره قابل فعال‌کردن است؛ هم‌زمان دو مسیر را فعال نکنید.
- بیلدر مرکزی هرگز API بازار یا مایکت را فراخوانی نمی‌کند. توکن‌های قبلی استورها در سورس حفظ شده‌اند؛ برای تست این مهاجرت استفاده نمی‌شوند. انتشار استوری فعلاً دستی است.
- تگ stores-vX.Y.Z روی همان commit ساخته می‌شود و Release در همین ریپو قرار می‌گیرد. Topic tgbot برای بات Cloudflare حفظ می‌شود. دسترسی App بیلدر و GH_TOKEN بات به ریپو مستقل‌اند.

بررسی محلی: npm test (۶۰ مرحله)، سپس با VITE_STORE برابر bazaar، myket یا debug دستور npm run build. برای Android، مقدار STORE را همین‌طور تنظیم و VERSION را به نسخهٔ موردنظر تعیین کنید و npm run build:android اجرا کنید. نسخه‌های استور به همان Secrets امضا و کلیدهای عمومی خرید احتیاج دارند. نسخهٔ Debug کلید استور لازم ندارد.
