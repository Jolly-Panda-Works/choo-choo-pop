# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it [privately on GitHub](https://github.com/Jolly-Panda-Works/choo-choo-pop/security/advisories/new) or write to contact@useffarahmand.com.

Include what you found, how to reproduce it, and the game version. You'll get an answer as soon as possible, and the fix will credit you if you'd like.

Exposed secrets and problems with in-app purchases or children's privacy are especially important to report.

The billing keys in the build settings and logs are public keys by design, so they aren't vulnerabilities.
